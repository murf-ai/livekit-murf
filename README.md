# Livekit Murf

![Murf AI Logo](https://murf.ai/public-assets/home/Murf_Logo.png)


Official [Murf AI](https://murf.ai/) Text-to-Speech integration for [Livekit](https://github.com/livekit/agents) - a framework for building voice and multimodal conversational AI applications.

> **Note**: This integration is maintained by Murf AI. As the official provider of the TTS service, we are committed to actively maintaining and updating this integration.


# Installation

```bash
pip install livekit-murf
```

## Pre-requisites

You'll need an API key from Murf AI. It can be set as an environment variable: `MURF_API_KEY`
